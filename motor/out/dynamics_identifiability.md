## Large steps from rest (a DIFFERENT process)

- steps found in this sweep: 3 (median SNR 4.9)
- best-fit tau: **100 ms** -- this regime is ESC start-up + rotor spin-up (T ~ omega^2), not the small-signal response, so it must NOT set the model's tau. The standard staircase sweep steps by 100 us and rarely returns to rest, so few high-SNR from-rest steps exist here; a dedicated large-step run would be needed to characterise spin-up properly.
